# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub instead :
**Security › Report a vulnerability** on this repository.

Describe the affected component, the version or commit, and how to reproduce the problem. You will get
an answer once the report has been reviewed, and the fix will be published together with a security
advisory crediting you, unless you ask otherwise.

## Supported versions

Only the latest release receives security fixes.
